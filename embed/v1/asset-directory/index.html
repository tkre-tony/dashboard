Asset Directory — embed reference

Integration guide and live preview for the asset_directory module.

Installation

Drop a container where the directory should appear, then load the script. Nothing else is required — no stylesheet, no build step, no framework.

<div id="pa-asset-directory"></div>
<script src="https://propertyatlas.sg/embed/v1/loader.js"
        data-pa-key="pk_your_key_here"
        data-pa-module="asset_directory"
        data-pa-target="#pa-asset-directory"></script>

Script attributes

AttributeRequiredMeaning
data-pa-keyYes The partner key issued by PropertyAtlas. Safe to publish — it is validated against a registered domain allowlist, so it is useless from any other site.
data-pa-moduleNo Defaults to asset_directory.
data-pa-targetNo CSS selector for the container. If omitted or not found, the embed is inserted immediately after the script tag.

Domain registration

Each key is bound to a fixed set of origins. A request from an unregistered domain is refused before any data is read, and the embed renders a short notice instead. Send PropertyAtlas every origin the embed will run on, including the www variant if you use one, and any staging domain.

Styling is taken from the partner theme held by PropertyAtlas — logo, four colour tokens and an optional font stack. The embed renders inside a shadow root, so it will not inherit or disturb surrounding site CSS. Attribution is part of the module and is not configurable at the page level.
